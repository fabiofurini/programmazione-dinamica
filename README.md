# Programmazione dinamica

Le dispense di programmazione dinamica: i principi della programmazione dinamica e gli algoritmi di PD per i problemi di zaino (0/1, illimitato, limitato, subset sum, a scelta multipla, multidimensionale, con setup, zaini multipli), il lot sizing senza capacità e capacitato, il cambio monete e il taglio delle aste, con esempi svolti, esercizi e app interattive.

**Sito: [fabiofurini.github.io/programmazione-dinamica](https://fabiofurini.github.io/programmazione-dinamica/)**
